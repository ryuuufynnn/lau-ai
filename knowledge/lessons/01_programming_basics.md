# Programming Basics

Programming is writing instructions that a computer can execute.

A programming language is the language used to express those instructions.

A program is a set of instructions written in a programming language.

Examples of programming languages:
- Python
- C
- C++
- Java
- JavaScript

Basic programming workflow:
1. Understand the problem.
2. Design a solution.
3. Write code.
4. Test the program.
5. Fix errors and improve it.
