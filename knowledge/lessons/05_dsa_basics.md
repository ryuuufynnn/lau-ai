# Data Structures and Algorithms

DSA means Data Structures and Algorithms.

A data structure is a way of organizing and storing data.

Examples:
- Array
- Linked list
- Stack
- Queue
- Tree
- Graph
- Hash table

An algorithm is a step-by-step procedure for solving a problem or completing a task.

Examples:
- Bubble sort
- Merge sort
- Binary search
- Linear search

Simple distinction:

Data structure = how data is organized.

Algorithm = how a problem is solved.
