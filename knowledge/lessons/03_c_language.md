# C Language

C is a general-purpose programming language.

C was developed by Dennis Ritchie at Bell Labs. Development began around 1969 and continued into the early 1970s.

If asked when C was created, avoid presenting only `1969` as the complete creation date. A better answer is:

Development of C began around 1969 at Bell Labs, and the language was developed during the early 1970s.

C is important in systems programming, embedded systems, operating systems, and performance-sensitive software.
