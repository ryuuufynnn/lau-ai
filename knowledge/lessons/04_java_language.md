# Java

Java is a high-level, general-purpose programming language.

Java supports:
- Classes and objects
- Inheritance
- Polymorphism
- Encapsulation
- Interfaces
- Generics
- Exception handling
- Multithreading

Important corrections:
- Java DOES support inheritance.
- Java DOES have generics.

Calling Java "underrated" is an opinion, not an objective technical classification. Answer such questions using factual information about Java and clearly identify opinions as opinions.
